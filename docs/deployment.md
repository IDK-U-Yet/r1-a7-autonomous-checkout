# 部署与运行目录

源码仓库和运行状态必须分离。本机 `runtime/` 用于保存不进入 Git 的数据集、检查点、诊断日志和环境。公开副本不包含结账上位机及其生产部署脚本。

```text
runtime/
├── datasets/
├── checkpoints/
└── logs/
```

数据集、权重、商品数据库及现场配置必须由使用者单独准备，不能提交到本仓库。运行环境应针对实际机器安装，不复制其他机器的 Python、Node.js 或原生依赖目录。

生产部署中的 `/opt`、`/var/lib`、`/var/log` 或 `/data` 是受 systemd、权限和备份策略约束的系统路径，不应改成相对路径。仓库内开发和集成脚本则统一使用相对仓库布局。
